# Lenguaje Ubicuo - AudioShare

Del lenguaje utilizado para AudioShare identificamos los siguientes principales conceptos del dominio

## Términos del dominio
|Término | Definición |
|---|---|
|Emisor| Dispositivo que inicia y transmite el audio|
|receptor| Dispositivo que recibe el audio|
|Sala| Espacio lógico donde se agrupan los participantes|
|Participante| Dispositivo conectado a una sala|
|Audio| Contenido que se transmite entre dispositivos|
|Sincronización| Coordinación del momento de reproducción entre los receptores|
|Estado de reproducción| Información relacionada con acciones como iniciar, pausar o reanudar|

Estos conceptos permiten identificar limites dentro del sistema y agrupar responsabilidades relacionadas en diferentes contextos delimitados
