== Decisiones de diseño

Las decisiones arquitectónicas se mantienen como ADR independientes y
alcanzables desde el repositorio.

* link:../../adr/0001-usar-monolito-modular.md[ADR-0001 — Selección del estilo arquitectónico]

ADR-0001 establece el uso de un monolito modular. La implementación actual
mantiene una única aplicación Node.js/Express y separa las responsabilidades
en los módulos `session`, `audio` y `sync`. El corte vertical A-01 además
utiliza persistencia mediante el almacén JSON de salas.

No se duplican aquí las decisiones contenidas en los ADR; esta sección
funciona como índice y punto de trazabilidad hacia los archivos reales.
