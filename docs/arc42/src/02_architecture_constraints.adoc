== Restricciones arquitectónicas

* La aplicación cliente objetivo es Flutter/Dart, null-safe y Material 3.
* Android y Web son plataformas iniciales.
* El backend Node.js/Express se conserva para comunicación entre dispositivos y persistencia SQLite.
* El cliente no accede directamente a SQLite ni realiza HTTP desde widgets.
* La solución debe operar dentro de una red Wi-Fi local.
* La captura y transmisión de audio físico están fuera del corte actual.
